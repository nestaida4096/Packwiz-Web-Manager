認証情報について

Fine-grained Personal Access Token はこのタブのメモリ内だけで使用し、保存しません。公開端末では使わず、必要最小限のリポジトリ権限にしてください。ページを再読み込みすると再入力が必要です。

1. GitHub 接続

必要な権限: 対象リポジトリの Contents: Read and write。認証は GitHub API への直接リクエストで行います。

2. Modrinth で Mod を検索・追加

更新候補の確認

更新候補を確認し、Mod ごとに変更予定への追加または却下を選択してください。この一覧に表示されているだけではコミット予定に追加されません。

まだ更新候補はありません。

3. リポジトリ内のファイル

index.toml に登録された .pw.toml 以外のファイルも一覧表示します。選択したファイルは index.toml から解除し、リポジトリからも削除対象にできます。

先に GitHub リポジトリへ接続してください。

ローカルファイルを追加

Modrinth 外の Mod/JAR や、config・resource pack など任意のファイルをリポジトリへ追加します。ファイルは直接 index.toml に登録され、SHA-256 を計算します。

上書きは行いません。1ファイル25 MiBまで。追加後は差分を確認してコミットしてください。

4. TOML / テキスト編集

手動編集は TOML 構文チェックを行います。Packwiz の全コマンドをブラウザーで実行する機能ではありません。

5. 差分確認・コミット

変更はコミットするまで GitHub に書き込まれません。複数ファイルをまとめてコミットします。

変更はありません。
