認証情報について

Fine-grained Personal Access Token はこのタブのメモリ内だけで使用し、保存しません。公開端末では使わず、必要最小限のリポジトリ権限にしてください。ページを再読み込みすると再入力が必要です。

1. GitHub 接続

必要な権限: 対象リポジトリの Contents: Read and write。認証は GitHub API への直接リクエストで行います。

2. Modrinth で Mod を検索・追加

接続後、pack.toml のバージョンを読み込みます。変更は「pack.toml に適用」で変更予定に追加されます。

更新候補の確認

更新候補を確認し、Mod ごとに変更予定への追加または却下を選択してください。この一覧に表示されているだけではコミット予定に追加されません。

CurseForge から追加

検索・ID指定には各自の CurseForge API キーが必要です。直接URL追加はAPIキーなしで利用できます。

CurseForge APIキーの管理画面。キーはこのブラウザーのCookieに保存されます。JavaScriptから読み取れるため、ページ上のスクリプトや開発者ツールから秘匿できる方式ではありません。信頼できるHTTPS配信元でのみ使用してください。

検索して追加

IDを指定して追加（検索不要）

Mod IDとFile IDを直接指定します。対象ファイルが pack.toml のMinecraft・ローダー条件に合うかAPIで確認します。

直接URLから追加（APIキー不要）

URL・ファイル名・ハッシュを指定します。Packwizのメタデータにはハッシュが必須です。CurseForgeのMod IDは設定されないため自動更新対象にはなりません。

4. TOML / テキスト編集

手動編集は TOML 構文チェックを行います。Packwiz の全コマンドをブラウザーで実行する機能ではありません。
